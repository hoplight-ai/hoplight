## Findings

### Medium: the sign-in route takes unlimited password guesses

Proof: api/grant.js and middleware.js hold no counter and no 429 (grep for limit, attempt, 429: nothing). POST /api/grant answers the sign-in page again on a wrong password, as fast as the caller can post. The password it checks is PRIVATE_SITE_PASSWORD, the same pair that opens quick-tools and every private page on hoplight.ai, plus SHARE_PASSWORD for the guest door. So this route, and its twins on quick-tools and hoplight.ai, are three open oracles for one password. A long random password makes this slow to exploit; nothing on file says how long it is.

Fix: a Vercel Firewall rate-limit rule on POST /api/grant on the gut-check project (20 requests per 15 minutes per address is generous for a person and useless for a guesser), or the limiter now on hoplight-site's own /api/grant (branch sitesec1, src/app/api/grant/route.ts) copied into api/grant.js. Owner: ethics-cards repo, or Whit in the Vercel dashboard. Size: ten lines or one dashboard rule.

### Low: a visitor's typed take is kept in the store

Proof: gut-check-game-2026-11-02.html line 735 on origin/main: `sig('react', { topic, card, round, reaction, typed, query: take.slice(0, 500) })`. The first 500 characters of whatever the visitor typed on a card go to /api/signal, where only email addresses and phone numbers are cut (src/lib/signal.ts scrub), then into public.tool_signals beside a daily visitor hash, country and region. A take can carry a name, a workplace or a view the person would not want kept.

Fix: either say so in one line under the take box ("What you type here is kept, without your name, to improve the deck"), or drop `query` from the react event and keep only `typed: true`. Owner: ethics-cards. Size: one line either way.

### Low: no Content-Security-Policy

Proof: live headers on /play: X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy no-referrer, Strict-Transport-Security with preload, X-Robots-Tag noindex. No Content-Security-Policy. The page is one HTML file with inline script, so a strict script policy is a project, but `frame-ancestors 'none'; object-src 'none'; base-uri 'self'; form-action 'self'` costs nothing and closes the plugin and base-tag tricks the other headers do not.

Fix: add that one header to the headers block in vercel.json. Owner: ethics-cards. Size: one line.

### Low: the page runs a script from another site

Proof: /play loads https://hoplight.ai/kit/signal.js (lines 432 and 1202 of the live page). If hoplight.ai is ever compromised, that script runs on Gut Check with the visitor's localStorage in reach. Same owner on both sides, so this is accepted; it is named so the dependency is on record.

Fix: none now. If the kit ever grows, pin it with Subresource Integrity or copy it into the repo.
