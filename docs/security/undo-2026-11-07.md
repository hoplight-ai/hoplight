## Findings

### Low: source links are drawn straight from the feed

Proof: src/lib/undo/federal-register.ts line 83 takes `html_url` from the Federal Register API as a string and src/app/(main)/undo/UndoAll.tsx line 137 renders it as an href. Nothing checks that the value starts with https://. The feed is the official API over HTTPS, so a bad value would need that service itself to be serving one; React escapes the attribute, so the only shape that matters is a `javascript:` value, which the API does not produce.

Fix: in the mapper, keep `html_url` only when it starts with `https://`, else drop the link. Size: one line. Owner: this repo.
